# Shortlist1 Reply Templates

Reusable trainer-facing and internal reply templates for repeated support scenarios.

Replace the bracketed placeholders before sending. Use the assigned Clahan representative's name in the signature.

## 1. Request Trainer Profile and Availability

Subject: Re: [Requirement / Domain] - Trainer Details Required

```text
Hi [Trainer Name],

We have received a training requirement for [Domain].
Please share the following details at the earliest:

- Updated CV / Trainer Profile
- Availability slots
- Commercials
- Relevant experience

Thanks & Regards,
[Sender Name]
```

## 2. Confirm Trainer Availability

Subject: Re: [Requirement / Domain] - Availability Confirmation

```text
Hi [Trainer Name],

Please confirm your availability for the [Domain] requirement on [Date / Range].
Once confirmed, we will share the profile with the client.

Thanks & Regards,
[Sender Name]
```

## 3. Request Updated Resume / LinkedIn

Subject: Re: [Requirement / Domain] - Updated Profile Needed

```text
Hi [Trainer Name],

Please share your updated resume and LinkedIn profile for the client review.
If available, please also include recent project and training highlights.

Thanks & Regards,
[Sender Name]
```

## 4. Request Course Outline / TOC

Subject: Re: [Requirement / Domain] - TOC Required

```text
Hi [Trainer Name],

Please share the detailed TOC / course outline for the [Domain] program.
Kindly include topic flow, duration, and any hands-on lab points.

Thanks & Regards,
[Sender Name]
```

## 5. Request Lab Requirements

Subject: Re: [Requirement / Domain] - Lab Setup Details

```text
Hi [Trainer Name],

Please confirm the lab requirements for this program.
Share any software, access, environment, or platform needs so we can align before the client discussion.

Thanks & Regards,
[Sender Name]
```

## 6. Share Interview / Meeting Slot

Subject: Re: [Requirement / Domain] - Interview Slot

```text
Hi [Trainer Name],

The client has requested an interview / discussion slot.
Please confirm your availability for [Date and Time].

Meeting details:
- Platform: [Google Meet / Teams]
- Link: [Meeting Link]

Thanks & Regards,
[Sender Name]
```

## 7. Commercial Confirmation

Subject: Re: [Requirement / Domain] - Commercials

```text
Hi [Trainer Name],

Please confirm your commercials for the [Domain] requirement.
If there are any travel, lab, or special cost items, please mention them clearly.

Thanks & Regards,
[Sender Name]
```

## 8. Payment / Invoice / PO Follow-up

Subject: Re: Invoice / Payment Status

```text
Hi [Trainer Name],

Please share the invoice against the completed session / training.
Once we receive the invoice, we will follow up with the client for the payment status.

Thanks & Regards,
[Sender Name]
```

## 9. Trainer Not Available

Subject: Re: [Requirement / Domain] - Unavailable

```text
Hi [Trainer Name],

Thanks for confirming.
We will note that you are not available for this requirement and will look for another suitable profile.

Thanks & Regards,
[Sender Name]
```

## 10. Internal Follow-up Note

Subject: Re: [Requirement / Domain] - Pending Action

```text
Hi Team,

The below item is still pending.
Please check and update the status for:
- Profile
- Availability
- Commercials
- Interview / client discussion

Thanks & Regards,
[Sender Name]
```
