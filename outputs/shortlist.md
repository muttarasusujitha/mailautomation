# Shortlist Reply Templates

Reusable client-facing reply templates for the repeated mail scenarios found in the mail set.

Replace the bracketed placeholders before sending. Replace `[Sender Name]` with the assigned representative's name and add `Clahan Technologies` below the name in every client reply.

## 1. Availability / Slot Confirmation

Subject: Re: [Requirement / Domain] - Trainer Availability

```text
Hi [Client Name],

Thanks for reaching out.

We have an experienced trainer available for the [Domain] training requirement.
Please find attached the trainer profile and the available slots for [Date / Day]:

- [Slot 1]
- [Slot 2]

Kindly let me know if you need any additional information or further details.

Thanks & Regards,
[Sender Name]
```
